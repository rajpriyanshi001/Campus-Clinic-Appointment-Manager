# Campus-Clinic-Appointment-Manager

## 📌 About the Project

Campus Clinic Appointment Manager is a student project aimed at simplifying the process of booking and managing medical appointments within a college campus.

The project is currently in the planning and initial development stage.

## 🎯 Objectives

- Simplify campus clinic appointment scheduling.
- Manage doctor information and availability.
- Reduce manual appointment management.
- Learn practical web development and database management.

## 🛠️ Planned Technologies

- **Programming Language:** Python
- **Backend:** Flask
- **Frontend:** HTML, CSS, Bootstrap
- **Database:** MySQL
- **Version Control:** Git & GitHub

## 🚀 Planned Features

- User registration and login
- Doctor details and availability
- Appointment booking and cancellation
- Appointment history
- Basic appointment management for the clinic administrator

## 📅 Project Status

Currently in the planning and setup phase. Features will be implemented step by step.
